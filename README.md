# Luna Eternal — Resource Pack

Texturas e interfaz de **PokeReport: Luna Eternal**.

Este repositorio existe por una razón técnica: Minecraft necesita una **URL
pública y estable** para descargar el resource pack al entrar al servidor. El
proyecto en sí (diseño, mod, economía) es privado.

El pack se descarga solo al conectar. **No hay que instalar nada a mano.**

## Qué hay dentro

Una fuente propia cuyos caracteres son imágenes y espacios de anchura
negativa. Eso permite dibujar fondos propios detrás de los menús sin que el
jugador instale ningún mod.

Se genera con `tools/gen_resourcepack.py` del repositorio principal.
